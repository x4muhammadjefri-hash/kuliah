# Tugas Praktikum Pemrograman Web

Repositori ini berisi kumpulan tugas mata kuliah Praktikum Pemrograman Web - Kelas B.

## Struktur Proyek
* **Tugas3** : Berisi file latihan HTML dan CSS (`teman.html` & `coba.css`).
* **Tugas4** : Berisi file Praktikum mandiri membuat skrip Node.js 
               > Membuat 6 data transaksi belanja dengan mencantumkan (id, barang, harga, qty, kategori)
               >menggunakan filter() untuk menyaring kategori tertentu, map() untuk menghitung subtotal tiap barang, dan reduce() untuk total keseluruhan.
               >serta merapkan destructuring dan arrow functions pada seluruh fungsi pemrosesan data. (`tugas-es6.mjs`).
